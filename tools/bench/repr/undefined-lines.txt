# The output lines of the differential programs whose value is undefined in C.
#
# asplice ends with copy_elements(from, root, 0, offset, elems1). When the
# array is spliced from itself and 0 < offset < elems1, source and target
# ranges overlap, and for every slot kind but STR (and OBJ once the array has
# been promoted) copy_elements copies them with memcpy (VMArray.c:951), which
# is undefined for overlapping ranges. The control prints what its memcpy
# leaves: a forward copy for some cases, a block pattern for others, never
# what memmove gives. The Zig array copies overlapping ranges with memmove
# semantics (the controller's ruling), so it is expected to differ from the
# control in these lines and in no others.
#
# diff.sh reads this file: when base and head differ only in lines listed
# here (same line count on both sides, same case name on each differing
# line), and the head prints on each of them what memmove-model.py computes
# (it models every entry below, the diff-raku ones included), it exits 3 and
# prints the differing lines with
# both values; a head that reaches exit 3 is recorded and put to the user,
# not passed silently. A listed line whose head value is not the model's is
# exit 1.
# Any difference outside the list is exit 1. Each side must still repeat
# these lines run to run (exit 2).
#
# One entry per line: <program> <case name>, the case name being the text
# before the first ": " of the output line. An entry covers both settings.
#
# How it was derived (traces/llm/bench/va-differential.md, section 5):
#   * the diff-nqp `<kind>.selfsplice.<case>` entries are printed by
#       python3 traces/llm/bench/va-differential-raw/selfsplice.py --list \
#           traces/llm/bench/va-differential-raw/diff-nqp-spesh.out
#     which models asplice twice, with a memmove and with a forward copy as
#     its last step, and lists the cases of the eleven memcpy kinds where the
#     two models differ (15 cases x 11 kinds; the model's forward copy is
#     what the STR kind prints in every one of them);
#   * `<kind>.selfsplice.twice` (two such splices in a row) and the diff-raku
#     entries are listed by the same rule, by hand: each is an nqp::splice of
#     an array of a memcpy kind from itself at an offset inside it.
# Not listed, because the C defines the result: every STR case, the
# `gc.*.promoted` cases (element by element; checked with a breakpoint for
# OBJ), self-splices at offset 0 or at the end, and Rakudo's own
# .splice(..., @self), which copies the replacement first.
