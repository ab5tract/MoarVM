# The output lines of the differential programs whose value is undefined in C.

# None, since the C array defines a splice of an array into itself (upstream
# b2cbdc57c, 6ee35f98a, 5febdef32, on this branch with the Zig array made to
# match): copy_elements copies with memmove, its element loop runs backwards
# when the source is the target and the target lies above the source, and
# asplice no longer moves start at offset 0 for a self-splice. The result is
# the splice from a clone of the array, on every kind and in every GC
# generation, in the C and in the Zig array alike (traces/llm/bench/cfix-S.md,
# cfix-mirror.md). The 195 entries this file listed before (the self-splices
# of the eleven kinds the C copied with an overlapping memcpy) are now
# compared like every other line.

# The mechanism is kept: diff.sh reads this file, and when base and head
# differ only in lines listed here (same line count on both sides, same case
# name on each differing line) and the head prints on each of them what
# memmove-model.py computes, it exits 3 and prints the differing lines with
# both values; a head that reaches exit 3 is recorded and put to the user,
# not passed silently. With no entry, any differing line is exit 1.
#
# One entry per line: <program> <case name>, the case name being the text
# before the first ": " of the output line. An entry covers both settings.
